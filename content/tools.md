# Useful Tools for Technical Writer

1. [Mermaid](https://mermaid.js.org/intro/)

Mermaid lets you create diagrams and visualizations using text and code.


2. [Document Comparison Software - Draftable](https://www.draftable.com/compare)

Draftable allows you to compare text, word documents or PDF files online.

3. [Hemingway Editor](https://hemingwayapp.com/)

Hemingway App makes your writing concise and correct.
